Requirement 3 – Mock Test Attempt Manager

Objective:

The objective of the Mock Test Attempt Manager is to develop a Java program that manages a student’s mock-test attempts. The program evaluates each attempt based on a passing score of 60, tracks the best score, calculates remaining attempts, and stops evaluation once the student passes.

Features:

* Manages up to 3 mock-test attempts
* Stores score, correct answers, and incorrect answers for each attempt
* Checks whether the student passed or failed
* Stops further attempts once the student passes
* Tracks the best score
* Displays the remaining attempts
* Shows attempt-wise performance
* Displays the final result
* Provides a recommendation/message based on the student’s performance

Java Concepts Used:

* while / do-while loop
* Increment operator (++)
* Decrement operator (--)
* Assignment operators (=, +=, etc.)
* Relational operators (>=, <, >, ==)
* Logical operators (&&, ||)
* Nested if-else conditions
* Ternary operator (? :)
* Variables and data types
* Conditional statements (if, else)
